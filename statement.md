# Project Statement

## Project Title
EduPredict AI: Student Performance Prediction and Early Intervention System

## Problem Statement
Educational performance is often reviewed after assessments have already occurred. A data-driven system can help organize academic indicators, estimate expected performance, identify potential risk levels, and provide structured study recommendations.

## Scope
The project covers student data entry, validation, preprocessing, exploratory analytics, machine learning prediction, risk classification, recommendations, dashboard visualization, and storage of prediction records.

## Target Users
- Students
- Faculty members
- Academic mentors/administrators

## High-Level Features
1. Student data management
2. Data preprocessing and analytics
3. ML-based score prediction
4. ML-based risk classification
5. Personalized recommendations
6. Dashboard and reporting
7. Prediction record storage
